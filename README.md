# Kabuki Wiki

Unofficial fan wiki for **Kabuki**, the Roblox yakuza street roleplay game by Oicho Kabu.

**[Kabuki Wiki](https://kabuki.wiki/)** covers what the game is, the confirmed facts and what is still unknown.

**[Kabuki codes](https://kabuki.wiki/codes/)** lists every code with its reward and status.

**[Kabuki rolls](https://kabuki.wiki/rolls/)** explains what rolls change and what they cost.

Found a new code or a mistake? Open an issue here.

Not affiliated with Roblox Corporation or Oicho Kabu.
